The context window (M4) explains why one component is dangerous. This module zooms out to the
whole system. A modern deployment is rarely just a model and a user — it's a model wired to
retrievers, tools, MCP servers, memory, and sometimes a live desktop. Every one of those is a
place untrusted data can enter, and every tool is a place the model can *act*.

## The two questions that organize everything

For any LLM system, two questions locate most of the risk:

1. **Where does untrusted data enter the context?** Retrieved documents, tool output, MCP
   responses, memory, and anything on a screen during computer use are all attacker-reachable.
   This is the prompt-injection surface (M8).
2. **What can the model *do*?** Every tool, credential and action widens the blast radius of a
   successful injection. The 2026 OWASP list moved "Excessive Agency" up precisely because
   agents now act on real systems (M6).

The modern defensive posture follows from these: since you can't make the context un-injectable
(M4), you **limit what a successful injection can reach** — least agency, egress controls,
confirmations, containment (M10, M14).
