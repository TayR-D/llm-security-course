## What this is

A hands-on course on LLM security for people who already know web and application
security but not the machine-learning internals. It runs from how models work, through
the attack landscape, into how frontier providers actually prevent misuse — with the
provider **guardrail comparison** at its core.

This is the **Phase 1 vertical slice**: the site shell plus three flagship interactives,
one from each layer of the course. The remaining modules slot in around them.

## How to read the interactives

Each one is a model of documented behavior, not a live measurement. Where a number
comes from a provider's own reporting, it is cited and dated. Attacks appear only as
defanged or historical examples — the course teaches mechanisms, never working payloads.
